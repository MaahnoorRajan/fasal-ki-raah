# Decision log

## Confirmed by the project owner

- Shift from Karachi parcel delivery to farm-to-market crop transport for smallholders in rural Sindh and Punjab.
- Build a real project and learn through the full development process.
- Start with Python and a mobile-friendly website.
- At least two hours per week are available.
- Help is needed to find people for discovery conversations.

## Proposed, not yet confirmed

- Django with server-rendered HTML for the first implementation.
- Working Urdu name: **Fasal Ki Raah (فصل کی راہ)**. ReturnRoad is the English working name.
- One crop that can travel without refrigeration, if suitable for the first route.
- A trusted coordinator can help with booking if interviews show that farmers prefer it.
- One fixed route corridor with explicit ordered stops.
- Driver-proposed prices and simulated payments in the demo.
- A demo deployment with fictional data before any real shipment pilot.

## Unresolved

- Pilot district, crop, village or collection point, and destination mandi or buyer.
- Who arranges and pays for freight today and whether sharing space improves the farmer's net proceeds.
- Evidence of recurring delivery problems and permitted spare vehicle capacity.
- Required language support and participants' device/connectivity needs.
- Package limits, loading responsibility, pickup arrangements, and cancellation rules.
- Whole-trip versus per-leg capacity accounting.
- Hosting budget and operational support for a later pilot.
- Course restrictions or external-code attribution requirements, if the project is submitted academically.

Implementation decisions should be updated here with their reasons and evidence. This file must not treat assumptions as completed research.

The current Python lab retains fictional Karachi stops as an exercise in route order; they are not a selected agricultural route.
